# M142 材料支持字段召回结果

## 结论

M142 已将混合形成方式字段重新纳入 PDF 抽取和定向补抽，并扩大了适用人群、费率
调整、险种转换的语义候选。第一轮三款产品均抽出了“适用人群”，且带有可回验 Evidence。
材料支持条件下的抽取率为：596 **92.86%**、5003 **87.50%**、1826 **88.00%**，
合计 **89.61%（69/77）**。

这里的分母只包含本次材料可以支持、且属于 PDF 抽取职责的字段：

```text
present 且 material_supported / material_supported
```

`ambiguous` 和 `unsupported` 单独列出，不作为模型漏抽；纯外部映射和纯 LLM 生成字段
也不进入这个分母。这个指标反映召回，不等同于人工准确率。

## 为什么费率可调/险种转换没有硬填

596 的材料出现家庭费率因子、核保/特定情形下提高费率等内容，但没有足够明确的
“产品一般费率可调”授权，因此继续保持 `unknown` 或 `ambiguous`，没有把局部费率
因子误判成“是”。三款材料也没有确认通用的险种转换规则，因此不把续保、附加险或
保险期间届满当作险种转换。

## 模型方差

在批准的 12 次调用内做了两轮独立试跑，每轮 6 次。第二轮结果为 596 **89.29%**、
5003 **79.17%**、1826 **68.00%**，5003 的适用人群出现随机漏回。第一轮结果保留为
前端展示版本，第二轮单独写入 `provider-run-m142-three-products-second.json`，用于
说明当前 qwen-plus 在长上下文全量抽取上的方差。后续应增加确定性重试/字段级采样聚合，
而不是继续放宽 Evidence 审计。

## 交付与边界

- 展示结果：`provider-run-m142-three-products.json`
- 独立方差结果：`provider-run-m142-three-products-second.json`
- 第一轮 run：`v5-trial-53049f7103b8b10a`，6 次 qwen-plus，3/3 产品有预览；
- 第二轮 run：`v5-trial-788b9a30d902608b`，6 次 qwen-plus，3/3 产品有预览；
- 两轮均为 `REVIEW_REQUIRED`，因为 Evidence/抽取缺口仍需审核；值没有因待核验而删除；
- 8091 后端和 5174 前端已指向第一轮 artifact；没有生产 DB、Candidate、Release、Active
  或 GitHub 写入。
- 前端曾因严格旧版产品键集合拒绝 M142 新增诊断字段，显示
  `V5_PROVIDER_TRIAL_CONTRACT_INVALID`；已修复为兼容旧 artifact 与 M142 扩展字段，
  刷新后 3/3 产品数据可见。

## 下一步

1. 对 `supported 但 unknown` 字段按字段级小批次再补抽，并保留首轮值作为回退；
2. 对长上下文请求做章节级并行和确定性合并，降低 qwen-plus 的整批随机漏回；
3. 为“费率可调/险种转换”建立明确的正例/反例人工金标后，再纳入准确率评估；
4. 前端增加材料支持、ambiguous、unsupported 的筛选和计数，便于区分材料缺失与模型漏抽。
