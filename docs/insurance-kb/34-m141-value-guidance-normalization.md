# Mission 141 · v5 取值类字段优化结果

## 做了什么

v5 工作簿的 `取值`列现在被编译成运行时约束：

- 没有稳定选项的字段继续按自由文本抽取；
- `是、否`、`短期/长期/终身`这类单选值进入单选约束；
- 带“多选”的字段进入多选约束，结果去重并按 Schema 顺序排列；
- 带“可为空”的字段保留为空语义；
- `其他`、`等`只作为允许扩展，不强行截断材料里的新值；
- 模型输出能明确对应标准值时才归一化，不明确时保留有 Evidence 的原文。

约束同时进入 LLM prompt 和回包处理。Evidence、三态和字段顺序校验没有放宽。

## 需要注意

这轮提升主要来自“取值说明进入结构化约束”和模型补抽成功，不代表所有字段都已
准确。三个产品仍是 `REVIEW_REQUIRED`，原因是部分引用需要人工复核。下一步应按
字段分别看：材料是否命中、模型是否选值、值是否归一化、Evidence 是否回验，而不是
只看总字段数。
